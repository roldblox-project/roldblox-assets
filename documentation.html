Getting Started

Templates use a simple tag-based syntax. Tags are wrapped in curly braces.

Important: File names must end with .tpl extension
Basic Structure
<!DOCTYPE html>
<html>
<head>
    <title>My Theme</title>
</head>
<body>
    <h1>Hello {$user_data["username"]}</h1>
</body>
</html>

Printing Variables

Display user data and other information using the dollar sign syntax.

Syntax
{$user_data["username"]}
{$user_data["robux"]}
{$get["id"]}
Available Data
Variable What it contains
$user_data Current logged-in user information
$get URL parameters (like ?id=123)
$page_data Extra data passed to the page
User Data Fields
idUser's ID number
usernameUsername
display_nameDisplay name
robuxRobux balance
ticketsTicket balance
powerStaff level (0=normal, 1+=staff)
membershipBC level (0=none, 1=BC, 2=TBC, 3=OBC)
is_verifiedHas verified badge (1 or 0)
HTML Escaping

By default, all variables are automatically HTML-escaped. To force escaping:

{escape $user_data["username"]}

If Statements

Show or hide content based on conditions.

Basic If
{if $user_data["power"] >= 1}
    <span class="badge bg-danger">STAFF</span>
{/if}
If/Else
{if $user_data["robux"] > 1000}
    <p>You're rich!</p>
{else}
    <p>Keep grinding!</p>
{/if}
Operators You Can Use
  • == equals
  • != not equals
  • > greater than
  • < less than
  • >= greater than or equal
  • <= less than or equal
  • && and
  • || or
Example
{if $user_data["membership"] >= 3}
    <span class="badge bg-warning">OBC</span>
{/if}

{if $user_data["is_verified"] == 1}
    <img src="/verified.png" alt="Verified">
{/if}

Loops

Repeat content for each item in a list.

Syntax
{foreach $friends as $friend}
    <div>{$friend["username"]}</div>
{/foreach}
Example with API
{api endpoint="/api/friends-list.php" var="data"}

{foreach $data["friends"] as $friend}
    <div class="card">
        <h5>{$friend["username"]}</h5>
        <p>Status: {$friend["status"]}</p>
    </div>
{/foreach}

Creating Links

Generate proper URLs with parameters.

Simple Link
<a href="{url page="games"}">Browse Games</a>
<a href="{url page="catalog"}">Shop</a>
Link with Parameters
<a href='{url page="users" id="123"}'>View User</a>
<a href='{url page="games" id="456" sort="popular"}'>View Game</a>
Dynamic Links
<a href='{url page="users" id="{$user_data["id"]}"}'>My Profile</a>

Thumbnails & Images

Display game icons, user avatars, and item thumbnails.

Game Icon
<img src='{asset type="PlaceIcon" id="123" size="150x150"}'>
User Avatar
<img src='{asset type="Head" id="{$user_data["id"]}" size="100x100"}'>
Catalog Item
<img src='{asset type="Asset" id="789" size="420x420"}'>
Available Types
  • PlaceIcon - Game/place thumbnails
  • Head - User headshots
  • Asset - Catalog items

Reusable Components

Split your theme into multiple files for easier management.

Create header.tpl
<!DOCTYPE html>
<html>
<head>
    <title>My Site</title>
</head>
<body>
    <nav>
        <a href="/">Home</a>
        <span>{$user_data["username"]}</span>
    </nav>
Create footer.tpl
    <footer>
        <p>© 2024 My Theme</p>
    </footer>
</body>
</html>
Use in home.tpl
{include file="header.tpl"}

<div class="content">
    <h1>Welcome!</h1>
</div>

{include file="footer.tpl"}

Fetching Data

Call site APIs to get dynamic content.

Basic Usage
{api endpoint="/api/home-recent" var="feed"}

{foreach $feed["games"] as $game}
    <div>
        <h3>{$game["title"]}</h3>
        <img src='{asset type="PlaceIcon" id="{$game["id"]}" size="150x150"}'>
    </div>
{/foreach}
Multiple API Calls
{api endpoint="/api/home-favorites" var="games"}
{api endpoint="/api/friends-list.php" var="friends"}

<h2>Games: {$games["total"]}</h2>
<h2>Friends: {$friends["count"]}</h2>

Important Notes
  • All files must end with .tpl
  • Variables are automatically HTML-escaped
  • You can't execute PHP code directly
  • Only approved API endpoints can be called
  • Themes are sandboxed for security
